# 천하진형 (Nadaero)

삼국지 + 진형 배치 로그라이크. 이름 없는 주인공 장수가 진형을 짜고 고을을 점령해 낙양까지 오릅니다.
폰 브라우저 우선, 빌드 없이 `index.html`을 열어 실행합니다. 한국어판이 최신 버전이며 `en/index.html`은 이전 버전입니다.

## 핵심 규칙
- **진형**: 4×5 격자에서 시작 3행, 고을 4개 점령 시 4행 해금. 어린진/학익진마다 사용 가능한 칸과 보너스가 다릅니다.
- **장수 크기**: 1칸·2칸·2×2 부대. 회전과 장비에 따라 공간을 다르게 사용하며 통솔은 점유 칸 수만큼 소모합니다.
- **전투**: 군령으로 카드를 사용한 뒤 합을 진행합니다. 기본 군령은 2, 손패는 합마다 4장입니다. 미사용 카드 한 장을 보관할 수 있고 나머지는 버림 더미로 갑니다. 보관할 카드도 사용하면 보관이 취소됩니다.
- **전술 카드**: 선봉 명령(아군 먼저 행동), 집중 공격(지정 적을 다음 일반 공격 2회가 우선 공격), 전열 교대(합법적인 인접 부대 교환), 추격 준비(다음 공격 처치에 인접 아군 추가 행동), 군령 비축(다음 합 군령 4).
- **처치 연쇄**: 보병 처치 시 바로 뒤 궁병이 70% 공격, 기병 처치 시 인접 기병이 60% 공격. 한 공격에서 추가 행동은 최대 3회이며 같은 장수는 한 번만 참여합니다. 지원 사격도 안개·비·방패 영향을 받습니다.
- **배치와 교대**: 교대 시 배치 보너스를 다시 계산하고 현재 체력 비율은 유지합니다. 통솔과 점유 공간을 지킬 수 있는 교대만 선택 가능합니다. 교대 후 배치는 다음 전투에도 유지됩니다.
- **적 행동 표시**: 현재 배치에 따른 다음 행동과 표적을 표시합니다. 앞선 처치·교대에 따라 표적은 달라질 수 있습니다.
- **환경**: 지형·날씨·바람에 따라 기병·화공·궁병 효과가 달라집니다.
- **성장**: 장수 합류, 장비, 카드, 주인공 능력치, 생존 장수의 전공·기술 선택.
- **패배**: 병량을 모두 잃으면 게임 오버입니다. 30합을 넘긴 전투도 패배합니다.
- **저장**: 타이틀에서 기존 저장을 덮어쓰지 않습니다. 전투 상태와 미선택 전리품·성장 보상도 이어하기로 복원됩니다. 저장은 현재 브라우저에만 유지됩니다.

## 검증
Node.js 22.13 이상에서 `npm ci` 후 `npm test`를 실행합니다. 게임 실행에는 Node.js나 npm이 필요하지 않습니다.
전투 규칙·저장 회귀 검사와 DOM 화면 흐름 검사를 포함합니다. DOM 검사는 실제 브라우저의 레이아웃 검사를 대신하지 않습니다.
