# 천하진형 (Nadaero)

삼국지 + 진형 배치 로그라이크. 이름 없는 주인공 장수가 진형을 짜고 고을을 점령해 낙양까지 오릅니다.
폰 브라우저 우선, 단일 HTML 파일. 한국어: `index.html` · English: `en/index.html`

## 핵심 규칙
- **진형**: 3×4 격자. 진법(어린진/학익진)에 따라 쓸 수 있는 칸과 보너스가 달라짐
- **자동 전투**: 속도 순으로 행동. 보병은 전열에서만, 기병은 2열에서도 공격. 궁병은 체력 낮은 적 저격, 책사는 적 전열 전체에 화계
- **인접 시너지**: 도원결의, 오호대장군, 수어지교, 와룡, 연환계, 숙적, 장판파 등
- **영역 점령**: 인접한 고을만 공략 가능. 점령하면 장수 합류·금·경험
- **성장**: 주인공 레벨업 시 능력치 선택, 군영에서 장수 단련
- **패배**: 병량 3개를 모두 잃으면 게임 오버
